# ROOM RUN — WebSocket 멀티플레이 테스트

방 생성/입장, 플레이어 위치 실시간 동기화, 룸 단위 채팅을 확인할 수 있는 작은 테스트 프로젝트입니다.

## 실행 방법

1. [Node.js](https://nodejs.org/) 18 이상을 설치합니다.
2. 압축을 푼 폴더에서 터미널을 열고 의존성을 설치합니다.

   ```bash
   npm install
   ```

3. 서버를 실행합니다.

   ```bash
   npm start
   ```

4. 브라우저에서 `http://localhost:3000` 을 엽니다.
5. 방을 만들고, 다른 브라우저 탭/시크릿 창에서 방 코드를 입력해 입장합니다.

## 포함 기능

- WebSocket(`ws`) 기반 실시간 연결
- 방 코드 생성 및 방 입장
- 방 안 플레이어의 위치/목록 실시간 동기화
- 방향키 / WASD / 화면 버튼으로 이동
- 방 단위 채팅
- 모바일 화면 대응 UI

## 구조

- `server.js`: Express 정적 파일 서버 + WebSocket 서버 + 방/플레이어 상태 관리
- `public/index.html`: 화면 구조
- `public/style.css`: UI 스타일
- `public/client.js`: WebSocket 클라이언트와 렌더링

## 테스트 시 주의

- 같은 컴퓨터에서는 `localhost:3000`을 여러 탭에서 열어 테스트할 수 있습니다.
- 다른 기기에서 테스트하려면 서버 컴퓨터의 LAN IP로 접속하고, 방화벽에서 TCP 3000 포트를 허용해야 합니다.
- 인터넷에 배포할 때는 HTTPS 환경에서 `wss://`를 사용하도록 리버스 프록시/호스팅을 설정하세요.
- 이 프로젝트는 데모용입니다. 인증, 입력 검증 강화, 레이트 리밋, 재접속 복구, 운영 환경 보안은 포함하지 않았습니다.
